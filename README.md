# Magic Castle — 하늘의 수호자

GitHub Pages에서 실행하는 30스테이지 2D 판타지 게임입니다. `index.html` → `cloud.js`, `script.js`가 실제 실행 경로입니다. `boot.js`와 `game.js`는 현재 실행되지 않는 예전 3D 시안입니다.

- 기사: 높은 체력, 근접 자동 공격, 자동 보호막
- 법사: 원거리 자동 마법 공격, 얼음 지팡이로 시작
- 기존 검사 기록은 기사, 마법사·치유사 기록은 법사로 이전하며 성장 기록을 보존합니다.
- 비밀의 문에 닿으면 보물방으로 이동합니다. 상자 보상은 스테이지당 한 번이며 오른쪽 포털로 돌아옵니다.
- 체크포인트에서는 회복·공격·점프 축복 중 하나를 선택합니다.
- 3연속 처치마다 콤보 동전 보상을 받습니다.

## 로컬 저장

게임 진행은 이 브라우저에만 저장됩니다. 구글 로그인, 클라우드 업로드, 인증 SDK를 사용하지 않습니다. 기존 기기 저장 키를 유지하여 이전 기록을 이어갑니다.

플레이 중 5초마다, 일시정지와 화면을 떠날 때 자동 저장하며 ‘이 기기에 저장’으로 직접 저장할 수도 있습니다. 처음 화면의 ‘모험 이어하기’로 재개합니다. 스테이지의 적·아이템·보물방·축복·체력·장비 상태를 보관하고 마지막 위치에서 재개합니다. 재개 직후 1.5초 무적을 제공하며 투사체와 시각 효과는 초기화합니다. 브라우저 데이터 삭제 또는 다른 기기에서는 진행 기록을 이어갈 수 없습니다.

## 로그인 없는 온라인 랭킹

게임 진행 저장과 별도로, 온라인 랭킹만 Supabase를 사용합니다. `leaderboard.js`는 별명, 직업, 난이도, 단계, 클리어 시간과 피해량만 전송합니다. 게임 진행 데이터는 전송하지 않습니다. 계정을 만들거나 구글을 연동할 필요가 없습니다. 브라우저에 생성한 무작위 식별값으로 같은 기기의 기록을 합산하고 서버에는 식별값의 해시를 보관합니다.

`supabase/setup.sql`을 SQL Editor에서 실행하면 로그인 없는 랭킹 API가 생성됩니다. 이전 클라우드 저장 API 권한은 차단하되 기존 서버 데이터는 삭제하지 않습니다. 새 설치에도 적용할 수 있습니다. RLS를 활성화하고 원본 테이블 직접 접근을 차단합니다.

난이도·직업별 상위 50명이며 완료한 단계 수 → 별 → 합산 시간 순입니다. 각 스테이지 최고 기록을 한 번만 집계합니다. 랭킹 화면에서 별명을 정하면 이후 스테이지 클리어 시 자동 등록됩니다. 최근 등록 대기 기록은 기기에 보관하여 재시도합니다. 중간 저장에서 불러온 스테이지는 제외하고 다음 스테이지부터 측정합니다. 데이터 삭제나 기기 변경 시 랭킹 식별값도 달라집니다.

서버는 식별값 소유 여부, 시작 시각, 시간·피해량 범위, 중복 등록과 기기별 분당 시작 횟수를 확인합니다. 클리어 자체를 서버에서 재현하지 않는 캐주얼 랭킹이며 완전한 부정행위 방지나 강한 요청 제한을 보장하지 않습니다.

## 검증

`node tests/game.cjs`로 기존 직업 변환, 저장/복원, 잘못된 저장 거부, 콤보·보물 중복 보상 방지, 랭킹 티켓 중복 방지, 30개 스테이지 업데이트·렌더링·저장을 확인합니다. 실제 배포 화면에서는 로그인 없는 랭킹 조회와 로컬 저장·이어하기를 확인합니다.

게임 배포는 기존 GitHub Pages 저장소 루트 구성을 사용합니다. 별도 빌드가 필요하지 않습니다.
