# Magic Castle — 붉은 여우검사

붉은 머리, 귀 장식, 민첩한 보폭과 전방 검술

완전한 기존 30스테이지 게임 로직을 공통 기반으로 사용합니다.
- 4개 직업, 직업 고정, 자동 공격, 2단 점프, 자동 보호막
- 30개 스테이지, 보스, 함정, 이동/붕괴 발판, 펫, 상점, 기록 및 브라우저 저장
- 2D Canvas로 새로 그린 측면/사선 캐릭터. 다리의 무릎과 발을 서로 다른 타이밍으로 걷도록 애니메이션 처리
- 이 버전은 주인공 디자인을 비교하기 위한 독립 게임이며 모델마다 별도 저장 데이터를 사용

GitHub Pages: 이 폴더의 내용을 저장소 최상위에 업로드하면 됩니다. 외부 CDN 불필요.
PC: A/D 또는 방향키 이동, Space 점프, Q/E 무기 교체. 모바일: 조이스틱 + 점프. 전투 자동.
